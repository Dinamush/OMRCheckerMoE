Fill answer bubbles (simulate a student marking q1–q25)

Used for every row that doesn't supply its own answers column. Accepts the same shortcuts as Single Sheet (random, random_with_skips, alternating, all_a…all_d, or a 25-letter string). Add an answers column to your CSV for per-row overrides.

Stamps a sequential page number on each PDF page in CSV order (resets to 1 inside each group when grouping is active). Ignored when output is a ZIP of single PNGs.

Wraps the output in a ZIP of ..._part_NN_of_TT.pdf segments, each kept within the operator-configured size and page caps so office MFPs (Xerox VersaLink, Ricoh IM, Canon iR-ADV, Konica bizhub, HP LaserJet Enterprise) accept each segment without Fault 016-751 / PostScript limitcheck errors. When grouping is active, the group name prefixes each segment, e.g. Berbice_part_01_of_03.pdf. Page numbers stay continuous across the segments of each region/school group. Adjust the size and page caps on the /settings page. Ignored when output is a ZIP of single PNGs (nothing to split).

Print N Blank Sheets

Generate N copies of an unfilled answer sheet for printing and handing out at the venue. The page raster is bundled with the application, so this is deterministic, offline, and very fast even for large counts.

Each variant ships as a single-page US-letter PDF whose page is cloned N times into the output. ArUco corner markers are baked into the source so each printed page is already alignable by the OMR engine.

Capped by the operator setting prefill_blank_max_sheets on the /settings page.

Stamps n / N at the bottom of each page so invigilators can hand out copies in order. Continuous across split segments when splitting is enabled below.

Wraps the output in a ZIP of blank_..._part_NN_of_TT.pdf segments, each kept within the size and page caps configured on the /settings page. Page numbers stay continuous across segments.
