# Portrait 25Q — v2 (optimised)

Sweep-validated successor to the legacy `portrait_25q` preset.

This preset is **opt-in**: it ships alongside the original `portrait_25q/`
directory and is only used when the operator flips the
`sheet_variant` setting to `v2_optimized` on the `/settings` page.
The default is `v1_legacy` so existing batches keep their original
behaviour with zero migration effort.

## What changed vs `portrait_25q/`

| Aspect | Legacy (`v1_legacy`) | Optimised (`v2_optimized`) |
|---|---|---|
| Candidate bubble diameter | 10 OMR-px (4.2 mm) | **12 OMR-px (5.0 mm)** |
| Candidate column spacing | 25.0 OMR-px (10.4 mm) | **28.0 OMR-px (11.7 mm)** |
| Candidate row spacing | 13.5 OMR-px (5.6 mm) | **15.0 OMR-px (6.2 mm)** |
| Answer bubble diameter | 13 OMR-px (5.4 mm) | **14 OMR-px (5.9 mm)** |
| Origin convention | Visual centre | **Top-left of sampling box** (matches engine) |
| `bubblesGap` / `labelsGap` (Candidate) | Swapped (engine looked at wrong cells) | **Correct for `QTYPE_INT`** |
| `referenceMarkerHalfSize` | (default 10) | **15** (matches the 30 OMR-px markers) |

## Provenance

Generated by `portrait_25q/variants/sweep/materialize_v2_preset.py` using
`SheetSpec(label="size_12", cand_bubble_diam=12, cand_bubbles_gap_x=28.0,
cand_labels_gap_y=15.0, cand_origin=(118, 252))`.

`size_12` was the sole candidate diameter that achieved **100 % digit
accuracy across every darkness level** (pen ink, dark / medium / light
pencil) in the 100-case sweep and **100 % on every detectable edge case**
(half-fill, off-centre, tick mark, full fill, stray mark) in the 30-case
edge stress test. See `portrait_25q/variants/sweep/run_sweep.py` and
`run_edge_cases.py`.

## Files

- `template.json` — engine template (page dimensions, bubble dimensions,
  field blocks, marker geometry).
- `config.json` — sets `processing_width`/`processing_height` equal to
  `pageDimensions` so the engine's homography stays in OMR-space units.
- `reference/blank_portrait_25q_v2.png` — print-ready 200 DPI US-Letter
  reference render.
